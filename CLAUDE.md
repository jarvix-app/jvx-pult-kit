# Особенности Claude Code

- Правила выше общие для всех моделей; этот файл добавляет только то, что относится к Claude Code.
- **Адъютант продакта** работает в каталоге этого набора: команды `.claude/commands/` и роль `.pult-role.md` сюда пишет
  `pult kit pull` с сервера (в git набора их нет), они видны только при запуске из этого каталога. Команды: `/utro`, `/den`, `/vecher`, `/nedelya`, `/mesyac`, `/razbor`, `/raund`, `/cikl`, `/sprint` (утро, день,
  вечер, неделя, месяц, разбор входящих, раунд вопросов, циклы проектов, личный спринт). Ритуал каждого запуска начинается с `pult context`.
- Расписание и сторож запускают адъютанта без человека: `claude -p "/utro"`. Там нет собеседника — не задавай
  вопросов в пустоту, а пиши продакту через `pult send` и фиксируй в `pult journal add`.
- Разрешения для запусков лежат в `.claude/settings.json`: разрешён только `pult`, сеть и веб закрыты. Если нужное
  действие не разрешено — не ищи обходной путь, а сообщи продакту.
- Агент сотрудника открывает Claude Code в **своём проекте**, а не в этом наборе. Команд `/…` адъютанта ему нет
  вовсе: сервер отдаёт их только токену `adjutant` или `product`.
- MCP: `claude mcp add --scope user pult -- pult-mcp` даёт те же операции инструментами `pult_*`.
